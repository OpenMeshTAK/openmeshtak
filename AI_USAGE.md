# AI Assistance Disclosure

OpenMeshTak is developed with the help of large language models (LLMs). They
are used for implementation, documentation, testing, debugging and review.

Security and the protection of user data are core considerations throughout
the project. Every change runs through automated checks, including route and
browser security tests, log redaction tests, linting, type checks and a
dependency audit. Each release image ships with a software bill of materials
(SBOM).

The project remains maintainer-led. The maintainer reviews and tests every
change before it is merged, and adapts or rejects suggestions as needed. TAK,
iTAK and Meshtastic compatibility is claimed only after testing with the real
client. The maintainer is responsible for project decisions and releases.

## Contributions

Contributions made with AI tools are welcome. The contributor must understand
the change, be able to explain it, and have the right to submit it under the
repository license.
